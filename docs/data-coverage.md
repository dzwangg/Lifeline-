# Data coverage report

Generated by `python -m chsim.ingest.load` (data version `lodes8-2009-2023.tiger2020.v1`). Every number below was computed from files retrieved by this repository's adapters; see `backend/data/raw/*/manifest.jsonl` for URLs, hashes and times.

## Observed and used for the baseline

- **LODES8 primary jobs (S24)**: WAC/RAC/OD JT01 for 2009-2023, all files checksum-verified. 396 tracts in Orange, Durham, Wake, Chatham and Alamance counties (2020 geography).
- Chapel Hill (2020 Census place blocks) workplace primary jobs: 44,769 in 2009, 50,889 in 2023. Resident primary jobs 21,351 in 2023; NC-only external workplace share 72.0%.
- Identity check: town workplace jobs = residents working in town + NC in-commuters + out-of-state in-commuters, every year.
- The 2020 Census place is not necessarily the current corporate limit (S01, retrieved separately).
- **TIGER 2020 (S02)**: tract geometry and rook adjacency; 21 tracts overlap the 2020 place.

## Observed evidence used as context or calibration (not baseline series)

- **Taxable real property (S05+S06)**: $12.88B, an unaudited current parcel snapshot.
  - Orange view repeats parcels through a building join: 60463 rows, 59655 unique PINs; deduplicated by PIN.
  - Orange rate code '22' is INFERRED to be the Chapel Hill town district (largest district; contains the UNC campus PIN). Verify against Orange County's rate-code table (S46).
  - Orange exemptions approximated by land-use codes starting 'EX'; elderly/veteran exclusions and deferrals are not in this view.
  - Values may mix pre- and post-2025 revaluation vintages; personal property and vehicles are excluded.
- **Restricted affordable units (S16)**: 1,138 units in Chapel Hill (FY2025 inventory); 898 have no affordability end date (unknown, not permanent).
  - One row per unit is assumed from the schema (PIN/address/bedrooms); verify before using as a stock count.
  - Most units have no Affordability_End_Date; unknown expiry is not 'never expires'.
- **Housing grants inventory (S13)**: 245 rows, $30.1M approved FY2007-FY2024; 30 development rows with approval and completion years (lag 0-5 fiscal years). Used as an observational delay distribution for the housing card, not as a causal effect.
  - Unit fields disagree (e.g. *Approved vs *ToDate vs *Completed2); row grain and cumulative semantics unverified.
  - TotalFundingDisbursed sums to far less than Total approved; disbursement coverage is incomplete, not zero spending.
  - 93 of 245 rows lack a completion year (unknown, not incomplete).
- **Downtown tenants (S36)**: stale 2020 downtown sample; reported, not used.

## Missing, blocked or unusable

- **ACS 5-year (S21)**: missing: credential. Rent and burden trajectories are unavailable; the rent level shown in the UI is the QuickFacts ACS 2019-2023 median gross rent already cited in `data/baselines.json`, with no MOE captured.
- **budget_actuals_S44**: Values are shifted one column right (Category holds Original_Budget, Original_Budget holds Revised_Budget, Revised_Budget holds YTD_Actual); Fiscal_Year, Account_Type and YTD_Actual are empty for all 1,061 rows. Fiscal year cannot be attributed and actuals are year-to-date, so the layer is not used for calibration.
- **permits_S10**: Columns are shifted (dates in Type_of_Work, owners in PIN); not used.
- **audits_S42**: Direct retrieval returned HTTP 403 from this environment.
- **Business establishment registry, grant applicants/awards/outcomes, hiring-subsidy contracts**: not publicly available; the business and hiring cards run on disclosed assumption ranges.
- **County assessment history, sales-tax distributions (S45), audited fund balances (S42)**: not acquired; the fiscal ledger uses labeled illustrative placeholders for these lines.
- **Construction constraints (S55-S62: terrain, soils, flood, wetlands, sewer capacity)**: not acquired; the housing card uses an assumed annual capacity cap, labeled as such.
